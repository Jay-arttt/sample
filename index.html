같은 스펙인데 어떤 회사에는 합격하고, 어떤 회사에는 떨어집니다. "자율적인 분위기"라고 쓰여 있어도 리더가 새로운 시도를 반기는 곳인지, 정해진 절차를 중요하게 여기는 곳인지는 공고만 봐서는 알 수 없습니다.

기업이 공고에 다 쓰지 못한 인재상,
커리어벗은 기업에게 직접 듣고 있습니다

커리어벗에서는 기업이 직접 풍토진단에 참여합니다. 리더는 어떻게 일하는지, 구성원에게 무엇을 기대하는지, 어떤 사람이 빠르게 녹아드는지를 기업 스스로 진단합니다.
